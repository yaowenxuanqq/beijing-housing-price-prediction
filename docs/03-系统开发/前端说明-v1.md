# 前端说明（M4b）

| 项目 | 内容 |
|---|---|
| 技术栈 | Vue 3.5 + Vite 6 + Element Plus 2.9 + ECharts 5 + Pinia + Axios |
| 语言 | JavaScript（非 TypeScript） |
| 主题 | 浅色专业风，主色 #2f6fed |
| 目录 | frontend/ |
| 联调后端 | http://127.0.0.1:8000/api/v1/ |

## 一、启动

```powershell
# 1) 后端
cd backend
..\.venv\Scripts\python.exe manage.py runserver

# 2) 前端（另开终端）
cd frontend
npm install
npm run dev
```

访问：http://127.0.0.1:5173/

Vite 已配置代理：`/api` → `http://127.0.0.1:8000`。


产物在 `frontend/dist/`（已 gitignore）。构建已启用按需注册与 vendor 分包：vue / Element Plus / ECharts / axios。当前 ECharts chunk 约 627 KB（gzip 209 KB）。

## 五、注意

1. 预测为**相对行情估值**，绝对价格依赖表单中的「当期区中位单价」。
2. 后端未启动时前端会提示请求错误；模型缺失时提示 503。
3. 概览页与可视化分析页使用 `Promise.allSettled`，单个接口失败只影响对应卡片，可单独重试。
4. 热力图使用经纬度散点，不绘制行政边界。
5. 预测区间为训练集内部时序 5 折残差校准结果，实测覆盖率 78.32%；属于经验校准区间，不是严格置信区间。
6. 当前为本地开发配置（CORS 全开、DEBUG=True），部署前需收紧。
