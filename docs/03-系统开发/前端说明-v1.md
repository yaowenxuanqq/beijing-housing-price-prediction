cd backend

cd frontend
npm install

## 五、注意

1. 预测为**相对行情估值**，绝对价格依赖表单中的「当期区中位单价」。
2. 后端未启动时前端会提示请求错误；模型缺失时提示 503。
3. 概览页与可视化分析页使用 `Promise.allSettled`，单个接口失败只影响对应卡片，可单独重试。
4. 热力图使用经纬度散点，不绘制行政边界。
5. 预测区间为训练集内部时序 5 折残差校准结果，实测覆盖率 78.32%；属于经验校准区间，不是严格置信区间。
6. 后端默认 `DEBUG=False`，CORS 仅允许本地 Vite 地址；本地调试可在 `.env` 中显式开启 DEBUG。
## 六、第一批扩展（2026-10-23）

1. **可解释估价**：`/predict` 调用 `/api/v1/predict/explain/`，在结果下方展示 TreeSHAP 特征贡献条形图和“基准估值 → 当前估价”的解释说明。
2. **相似成交**：估价成功后自动检索同区域、近面积段历史成交，展示相似度、匹配原因与链家原始链接。
3. **预测记录**：新增 `/predictions` 页面，可筛选模型版本和日期，查看输入特征、价格区间、推理耗时，并导出 CSV。
4. **模型状态**：模型对比页顶部显示服务就绪状态、模型版本、特征数、累计估价次数、平均耗时与模型文件指纹。
5. **前端质量门**：ESLint 0 error，Vitest 10/10，生产构建通过。
## 七、第二批扩展（2026-10-23）

1. **What-if 情景对比**：预测结果页支持选择“加装电梯、变为近地铁、房龄减少 5 年、面积增加 10㎡”，调用情景接口并展示相对基准的总价变化。
2. **批量估价**：新增 `/batch` 页面，支持下载 CSV 模板、上传文件、展示成功/失败行、导出完整结果。
3. **模型运行趋势**：模型对比页增加近 7 天估价次数与平均耗时折线图。
4. **来源区分**：预测记录新增单条、可解释、情景、批量来源标签和批次编号筛选。
