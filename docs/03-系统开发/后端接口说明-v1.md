## 三、预测接口

### 请求

```json
{
  "district_name": "朝阳区",
  "square": 89.5,
  "rooms": 2,
  "halls": 1,
  "bathrooms": 1,
  "floor_position": "中",
  "total_floors": 18,
  "house_age": 12,
  "renovation": 3,
  "building_type": 1,
  "building_structure": 2,
  "ladder_ratio": 2,
  "elevator": true,
  "subway": true,
  "five_years": true,
  "market_median_unit_price": 66421
}
```

`market_median_unit_price` 为必填：该区**当期**成交中位单价（元/㎡），可从 `/meta/options/` 获取 2017 年默认值。

### 响应

```json
{
  "ratio": 1.197,
  "predicted_unit_price": 79508.0,
  "predicted_total_price": 711.6,
  "interval_low": 64200.0,
  "interval_high": 91800.0,
  "interval_total_low": 574.6,
  "interval_total_high": 821.6,
  "interval_level": 0.8,
  "interval_method": "time_series_cv_residual_quantile",
  "interval_note": "仅使用训练集内部时序折外残差；经验校准区间，不是严格置信区间。",
  "market_median_unit_price": 66421.0,
  "model_version": "tuned_rf_es3_v2",
  "currency": "CNY",
  "unit": "万元",
  "note": "相对行情估值；绝对价格依赖输入的当期该区中位单价"
}
```

### 预测区间说明

接口返回 80% **时序交叉验证校准区间**：仅在训练集内部执行 `TimeSeriesSplit(5)`，汇总折外 ratio 残差并取 q10/q90，再以 `ratio + [q10, q90]` 构造区间。

- 当前模型 q10 = -0.137104，q90 = 0.188645；
- 独立测试集 88,135 行实测覆盖率 78.32%；
- 校准区间宽度随输入特征和当期行情变化，不是常数区间；
- 该区间是**经验校准区间，不是严格置信区间**，不表示未来房价走势；
- 旧模型或无校准元数据时回退到树间 p10–p90，并通过 `interval_method` 显式标识。

### 计算链路

```
特征 → 完整 Pipeline（预处理 + RF）→ ratio
→ clip(ratio, 0.05, 9.0)            # 防外推爆炸
→ 单价 = ratio × market_median_unit_price
→ 总价 = 单价 × 面积 / 10000
```

## 五、健壮性约束（2026-10-21 修复）

| 场景 | 行为 |
|---|---|
| `district_name` 不在 13 个有效区名内 | **400**，错误信息列出全部可选区名（修复前会静默按东城区处理） |
| `min_price` / `max_price` / `min_square` / `max_square` 非数字 | **400**，返回「必须为数字」 |
| `subway` / `elevator` 非 0/1 | **400**，返回「只能为 0 或 1」 |
| `ratio × market_median_unit_price` | 与 `predicted_unit_price` 一致（误差 < 1 元） |
| `/stats/correlation/` | 随机取样 2 万行并缓存；响应含 `leakage_fields` 标注 |

**回归实测**：
- 火星区 → 400（列出 13 个区）
- community_average ~ unit_price：由 0.9373 回落到 **0.6924**（全量 0.6851）
- min_price=abc → 400
- 1.197031 × 66421 = 79,508.0 = predicted_unit_price

## 六、注意事项

1. 预测口径为**相对行情估值**：绝对价格依赖输入的当期区中位单价，论文与答辩须如实说明。
2. 模型加载为进程内单例；模型文件缺失时接口返回 503。
3. 当前 DEBUG=True、CORS 全开，仅用于本地开发；部署需收紧。
4. 数据库与模型文件均不入库（见 .gitignore）；换机后按“初始化”重建即可。
