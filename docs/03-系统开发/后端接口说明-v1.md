## 三、预测接口

### 请求

```json
{
  "district_name": "朝阳区",
  "square": 89.5,
  "rooms": 2,
  "halls": 1,
  "bathrooms": 1,
  "floor_position": "中",
  "total_floors": 18,
  "house_age": 12,
  "renovation": 3,
  "building_type": 1,
  "building_structure": 2,
  "ladder_ratio": 2,
  "elevator": true,
  "subway": true,
  "five_years": true,
  "market_median_unit_price": 66421
}
```

`market_median_unit_price` 为必填：该区**当期**成交中位单价（元/㎡），可从 `/meta/options/` 获取 2017 年默认值。

### 响应

```json
{
  "ratio": 1.197,
  "predicted_unit_price": 79508.0,
  "predicted_total_price": 711.6,
  "interval_low": 64200.0,
  "interval_high": 91800.0,
  "interval_total_low": 574.6,
  "interval_total_high": 821.6,
  "interval_level": 0.8,
  "interval_method": "time_series_cv_residual_quantile",
  "interval_note": "仅使用训练集内部时序折外残差；经验校准区间，不是严格置信区间。",
  "market_median_unit_price": 66421.0,
  "model_version": "tuned_rf_es3_v2",
  "currency": "CNY",
  "unit": "万元",
  "note": "相对行情估值；绝对价格依赖输入的当期该区中位单价"
}
```

### 预测区间说明

接口返回 80% **时序交叉验证校准区间**：仅在训练集内部执行 `TimeSeriesSplit(5)`，汇总折外 ratio 残差并取 q10/q90，再以 `ratio + [q10, q90]` 构造区间。

- 当前模型 q10 = -0.137104，q90 = 0.188645；
- 独立测试集 88,135 行实测覆盖率 78.32%；
- 校准区间宽度随输入特征和当期行情变化，不是常数区间；
- 该区间是**经验校准区间，不是严格置信区间**，不表示未来房价走势；
- 旧模型或无校准元数据时回退到树间 p10–p90，并通过 `interval_method` 显式标识。

### 计算链路

```
特征 → 完整 Pipeline（预处理 + RF）→ ratio
→ clip(ratio, 0.05, 9.0)            # 防外推爆炸
→ 单价 = ratio × market_median_unit_price
→ 总价 = 单价 × 面积 / 10000
```

## 六、注意事项

1. 预测口径为**相对行情估值**：绝对价格依赖输入的当期区中位单价，论文与答辩须如实说明。
2. 模型加载为进程内单例；模型文件缺失时接口返回 503。
3. 默认配置为 `DEBUG=False`，CORS 仅允许本地 Vite 地址；本地开发可在 `.env` 中显式开启调试。\n4. 模型异常日志保留在服务端，接口只返回通用错误与 request_id，避免泄露内部细节。
4. 数据库与模型文件均不入库（见 .gitignore）；换机后按“初始化”重建即可。
## 七、第一批扩展（2026-10-23）

### 7.1 可解释估价

```text
POST /api/v1/predict/explain/
```

请求体与 `/predict/` 相同。响应在普通预测字段之外增加：

```json
{
  "explanation": {
    "method": "TreeSHAP",
    "base_ratio": 1.01728,
    "raw_ratio": 1.19703,
    "predicted_ratio": 1.197031,
    "base_unit_price": 67569,
    "clip_adjustment_ratio": 0,
    "features": [
      {
        "feature": "dist_to_center",
        "label": "距市中心距离",
        "value": 7.59,
        "contribution_ratio": 0.1192,
        "contribution_unit_price": 7920
      }
    ],
    "top_positive": [],
    "top_negative": [],
    "method_note": "基于随机森林 TreeSHAP 的局部特征贡献，反映模型关联，不是因果推断。"
  }
}
```

- 使用进程内单例 `TreeExplainer`，不会每次请求重建解释器。
- 贡献值统一换算为“元/㎡”，便于前端直接展示。
- `clip_adjustment_ratio` 表示 ratio 保护性截断带来的调整量。

### 7.2 相似历史成交

```text
GET /api/v1/houses/similar/?district_name=朝阳区&square=89.5&rooms=2&subway=true&elevator=true&limit=10
```

- 同区域检索，面积默认上下浮动 30%；
- 优先近两年成交，不足时回退到同区同面积段全历史；
- 综合面积、户型、楼层、地铁、电梯与成交时间计算相似度；
- 返回 `similarity_score`、`area_delta_pct`、`match_reasons` 与原始房源链接。

### 7.3 预测记录

- `PredictionLog` 新增：`request_id`、`duration_ms`、`interval_method`、`response_json`；
- `/predictions/` 支持 `model_version`、`date_from`、`date_to` 过滤；
- `/predictions/export/` 输出带 UTF-8 BOM 的 CSV，Excel 中文可直接打开；
- 请求编号可用于把前端展示、数据库记录和服务日志关联起来。
