# 前端说明（M4b）

| 项目 | 内容 |
|---|---|
| 技术栈 | Vue 3.5 + Vite 6 + Element Plus 2.9 + ECharts 5 + Pinia + Axios |
| 语言 | JavaScript（非 TypeScript） |
| 主题 | 浅色专业风，主色 #2f6fed |
| 目录 | frontend/ |
| 联调后端 | http://127.0.0.1:8000/api/v1/ |

## 一、启动

```powershell
# 1) 后端
cd backend
..\.venv\Scripts\python.exe manage.py runserver

# 2) 前端（另开终端）
cd frontend
npm install
npm run dev
```

访问：http://127.0.0.1:5173/

Vite 已配置代理：`/api` → `http://127.0.0.1:8000`。

## 二、页面

| 路由 | 页面 | 内容 |
|---|---|---|
| /dashboard | 概览大屏 | 4 个指标卡 + 各区均价 + 空间热力图 + 年度趋势 |
| /houses | 数据管理 | 筛选条 + 表格 + 分页 + 详情抽屉 |
| /analysis | 可视化分析 | 总价分布、面积-总价散点、相关性矩阵、特征重要性 |
| /models | 模型对比 | 基线与调参结果表 + R² 对比图 + 3 种子稳定性 |
| /predict | 房价预测 | 表单 + 结果卡（单价/总价/ratio/模型版本） |

## 四、构建

```powershell
cd frontend
npm run build
```

产物在 `frontend/dist/`（已 gitignore）。构建已启用 vendor 分包：vue / element-plus / echarts / axios。

## 五、注意

1. 预测为**相对行情估值**，绝对价格依赖表单中的「当期区中位单价」。
2. 后端未启动时前端会提示请求错误；模型缺失时提示 503。
3. 热力图使用经纬度散点，不绘制行政边界。
4. 当前为本地开发配置（CORS 全开、DEBUG=True），部署前需收紧。
