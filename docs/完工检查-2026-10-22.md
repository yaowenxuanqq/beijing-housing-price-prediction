## 三、发现的问题

### P1-1 概览大屏热力图颜色映射失效（唯一需要修的）

**现象**：`docs/screenshots/dashboard.png` 中「房价空间分布」的全部散点为**同一深蓝色**，无任何蓝→红梯度。西城区大量 5–10 万单价房源应显示橙红色，实际全蓝。

**两个叠加原因**：

1. `DashboardView.vue` 的 `visualMap` 硬编码 `min: 20000, max: 120000`。实测单价分布：**7.55% 低于 20000**（最低 3,006 元/㎡），**0.75% 高于 120000**——即使映射生效也有 8.3% 的点被截断为两端色。
2. series 数据为 `[lng, lat, 区名字符串, unit_price]` 且开启 `large: true`，未显式指定 `dimension`，颜色映射疑似作用到了错误维度（lng ≈ 116，恒小于 min → 全部映射为最低色深蓝），与截图表现吻合。

**修复**（`frontend/src/views/DashboardView.vue` 的 `heatmapOption`）：

```js
visualMap: {
  dimension: 3,                      // 显式指定映射第 4 维（unit_price）
  min: 15000, max: 120000,           // 或由后端返回 p2/p98 后动态传入
  ...
},
series: [{
  type: 'scatter', symbolSize: 4,    // 可去掉 large（5000 点不需要）
  data: heatmap.value.map(r => [r.lng, r.lat, r.district, r.unit_price]),
  ...
}]
```

改完后热力图应呈现清晰的蓝（远郊低价）→ 红（城六区高价）空间梯度——这是答辩演示里最能直观体现「区位决定房价」的一张图。

### P2 问题（按影响排序）

| # | 问题 | 说明与建议 |
|---|---|---|
| 1 | **ES-4 无调参数据，页面无提示** | `metrics_tuned_v1.json` 只调了 ES-1/2/3。切到 ES-4 时「调参后结果」表与图中「调参后」系列为空，用户会以为坏了。建议：ES-4 时在表区域显示「该实验未纳入调参范围」的占位提示 |
| 2 | **`mae` 字段口径不一致** | ES-1/2 的 `mae` 是总价（万元，约 75–200），ES-3/4 的 `mae` 实为单价（元/㎡，约 5000–11000）。前端 `row.mae_unit_price ?? row.mae` 回退碰巧正确，但直接读 JSON 必踩坑。建议在生成端统一字段名，或至少在 JSON 里加注释性字段说明 |
| 3 | **README 残留 4 处过时表述** | 第 24 行「待接入前端」、第 95 行「前端 M4b 待开发」、第 102 行「依赖清单待生成」、第 15 行「进入系统开发阶段」——均已与现实不符，答辩前应更新为「系统已完成」 |
| 4 | **`Promise.all` 无失败降级** | Dashboard/Analysis 两页任一接口失败会导致整页数据空白（其他成功接口的数也不会渲染）。建议改 `Promise.allSettled`，失败的图卡显示空态而非整页空白 |
| 5 | **echarts/element-plus 全量引入** | 首屏 gzip 约 690 KB（echarts 343 KB + element 302 KB）。本机与校园网无碍，答辩现场若网络差首屏会慢 2–3 秒。可选优化：`echarts/core` 按需注册（可减约 60%）；element-plus 按需插件 |
| 6 | **`_CORR_CACHE` 无失效机制** | 数据集固定（2011–2017）时无碍；若日后 `load_data` 换数据，相关性矩阵会一直返回旧值。建议缓存时记一行数（`House.objects.count()`）做失效判断 |
| 7 | **`.env.example` 硬编码绝对路径** | `MODEL_PATH=C:/姚文轩/毕业设计/...` 换机即失效。`settings.py` 的 default 已是相对 PROJECT_ROOT 的更好方案，建议 example 里删掉该行或写相对说明 |
| 8 | **分页组件可能重复请求** | `size-change` 中 `page=1; load()` 与 `current-change` 可能连续触发两次 `load`。无害但会闪两次 loading，可加节流或在 size-change 里仅改页码 |
