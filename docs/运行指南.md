## 二、首次完整运行

### 步骤 1：进入项目并激活虚拟环境

    cd C:\姚文轩\毕业设计
    .\.venv\Scripts\Activate.ps1

若提示「禁止运行脚本」：

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    .\.venv\Scripts\Activate.ps1

### 步骤 2：安装 Python 依赖（已安装可跳过）

    python -m pip install -r requirements.txt

### 步骤 3：数据与模型流水线（已生成可跳过）

当前这些文件已存在，日常运行系统不需要重跑：

    python scripts\01_clean_data.py    # 清洗（约 10 秒）
    python scripts\02_eda.py           # EDA 图表（约 15 秒）
    python scripts\03_train.py         # 基线四实验（约 4 分钟）
    python scripts\04_tune.py          # ratio 调参（约 5 分钟）
    python scripts\05_stability.py     # 3 种子稳定性（约 1 分钟）

### 步骤 4：启动后端（终端 A，保持不关）

    cd C:\姚文轩\毕业设计\backend
    ..\.venv\Scripts\python.exe manage.py migrate
    ..\.venv\Scripts\python.exe manage.py load_data
    ..\.venv\Scripts\python.exe manage.py runserver

- migrate：建表（首次）
- load_data：导入 317,718 行（首次；会清空后重建）
- 服务地址：http://127.0.0.1:8000

可选——创建后台管理员：

    ..\.venv\Scripts\python.exe manage.py createsuperuser

### 步骤 5：启动前端（终端 B，保持不关）

    cd C:\姚文轩\毕业设计\frontend
    npm install     # 首次
    npm run dev

服务地址：http://127.0.0.1:5173

## 六、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| ImportError: DLL load failed | 升级了 numpy/pandas/sklearn | 重新 pip install -r requirements.txt，不要升级版本 |
| ModuleNotFoundError: django | 用了系统 Python 而非虚拟环境 | 使用 .venv\Scripts\python.exe，或先激活 venv |
| 端口 8000 被占用 | 已有进程 | manage.py runserver 127.0.0.1:8001，并同步修改 frontend/vite.config.js 代理 |
| 前端端口被占用 | 5173 已用 | Vite 会自动换端口，看终端输出 |
| 模型文件不存在 | 未跑调参 | python scripts\04_tune.py 与 05_stability.py |
| 数据库为空 | 未导入数据 | manage.py load_data |
| 前端请求 404 | 后端未启动 | 先启动后端 8000 |
| npm run build 报 esbuild 错误 | 安装脚本未执行 | npm rebuild esbuild |
