# 探索性数据分析（EDA）结果摘要

- 数据规模：317,718 行 × 28 列（clean.parquet）
- 时间范围：2011-01-01 ~ 2017-12-31

## 1. 价格分布

- 总价：中位数 295 万，均值 349.6 万，p99 1200 万，最大 4900 万
- 总价偏度 2.90 → 右偏严重，**建模需做 log1p 变换**
- 单价：中位数 38782 元/㎡，均值 43619 元/㎡

## 2. 区域差异

| 区域 | 样本量 | 均价（元/㎡） |
|---|---|---|
| 西城区 | 31,237 | 67,654 |
| 东城区 | 17,054 | 62,006 |
| 海淀区 | 38,088 | 54,952 |
| 朝阳区 | 107,070 | 43,649 |
| 丰台区 | 29,278 | 38,211 |
| 石景山区 | 11,355 | 35,181 |
| 亦庄 ⚠️ | 2,534 | 31,337 |
| 大兴区 | 15,289 | 30,027 |
| 昌平区 | 38,239 | 29,635 |
| 房山区 ⚠️ | 2,951 | 28,329 |
| 门头沟区 ⚠️ | 1,507 | 27,697 |
| 通州区 | 13,950 | 27,477 |
| 顺义区 | 9,166 | 24,287 |

- 最高：西城区 67,654 元/㎡；最低：顺义区 24,287 元/㎡
- 最高/最低比 ≈ 2.79 倍

## 3. 面积与总价

- 面积与总价相关系数 r = 0.573 → 面积是总价的强预测因素
- 面积与单价相关系数 r = -0.166 → 面积对单价影响较弱

## 4. 相关性

与总价相关性最强的字段：

- unit_price: r = 0.630
- square: r = 0.573
- bathrooms: r = 0.448
- rooms: r = 0.441
- community_average: r = 0.428
- halls: r = 0.328

## 6. 类别特征效应

- 电梯：44,555 vs 42,340 元/㎡，差值 2,215
- 近地铁：47,700 vs 37,452 元/㎡，差值 10,248
- 满五年：43,794 vs 43,298 元/㎡，差值 496
- 楼层位置：最高 底（44,550，n=25,941），最低 未知（38,748，n=1,268）
> ⚠️ 楼层位置的均价差异同样受**区位与楼栋类型混淆**影响（如「底」层样本多分布于老小区），不可直接作因果解读。

## 7. 房龄效应

- 0-5 年：36,535 元/㎡（n=25,975）
- 6-10 年：38,230 元/㎡（n=74,103）
- 11-15 年：41,877 元/㎡（n=71,947）
- 16-20 年：42,775 元/㎡（n=46,076）
- 21-30 年：51,810 元/㎡（n=59,853）
- 31+ 年：59,967 元/㎡（n=20,449）

> ⚠️ **因果解读警告**：上表显示房龄越大单价越高，这是**区位混淆**的结果，不是「老房更值钱」。
> 北京老房集中在西城、东城、海淀等核心区，新房多在远郊，房龄与区位高度混杂。
> 此表仅反映边际相关性，**不可解读为因果关系**。

- 佐证：房龄中位数最低的区域为 房山区（5 年），最高为 西城区（22 年）

## 8. 建模前须注意的数据问题

- house_age 缺失 6.08%（须在训练 Pipeline 内用**训练集**统计量填充）
- total_floors 缺失 0.40%（须在训练 Pipeline 内用**训练集**统计量填充）
- construction_year 缺失 6.05%（须在训练 Pipeline 内用**训练集**统计量填充）
- building_type 缺失 0.63%（须在训练 Pipeline 内用**训练集**统计量填充）
- community_average 缺失 0.14%（须在训练 Pipeline 内用**训练集**统计量填充）
- 单价与总价存在数学换算关系，建模时二者互斥使用（见计划书 4.5）
- community_average 与目标高度相关，建模一律排除
