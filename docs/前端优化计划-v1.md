## 二、优化原则

1. **专业优先**：数据系统不是炫技页，动效服务于信息层级，不干扰阅读。
2. **轻量实现**：优先 CSS / Canvas / IntersectionObserver，不引入 3D 与动效库。
3. **可降级**：尊重 prefers-reduced-motion；触屏设备关闭鼠标跟随效果。
4. **性能可控**：ECharts 按需引入，动画只用 transform / opacity。
5. **不换架构**：保留 Vue 3 + Element Plus，React Bits 只作为效果参考。

---

## 三、React Bits 取舍

### 3.1 采用的 4 个效果

| 效果 | React Bits 对应 | 用在哪 | 实现方式 |
|---|---|---|---|
| 数字滚动 | counter | 概览页 4 个指标卡 | requestAnimationFrame + 缓动 |
| 鼠标光斑卡片 | spotlight-card | 指标卡、图表卡、预测结果卡 | CSS 变量 --mx/--my + mousemove |
| 区块渐入 | fade-content / animated-list | 每个页面区块依次进入 | IntersectionObserver + transform/opacity |
| 点阵背景 | dot-grid | 概览页顶部横幅、页面留白 | CSS radial-gradient |

### 3.2 明确不采用

| 类别 | 示例 | 原因 |
|---|---|---|
| WebGL / 3D | model-viewer、lanyard、ballpit、liquid-chrome、orb | 包体过大（300KB–2MB），投影机可能卡顿 |
| 光标特效 | ghost-cursor、pixel-trail、splash-cursor | 干扰阅读，触屏无效 |
| 导航替换 | dock、bubble-menu、gooey-nav | 现有侧边栏信息架构更清晰 |
| 文字花活 | glitch、scramble、CRT | 与学术系统气质不符 |

> 不复制 React Bits 源码；仅按其视觉思路用 Vue 重写，避免许可与框架依赖问题。

## 四、阶段 A：视觉升级（1.5 天）

### A1 设计令牌

新增 src/styles/tokens.css，统一：

| 类别 | 令牌 |
|---|---|
| 颜色 | --color-primary #2f6fed、--color-success #13c2c2、--color-warning #faad14、--color-danger #f5222d |
| 背景 | --bg-page #f7f9fc、--bg-card #ffffff、--border-subtle #eef1f6 |
| 文字 | --text-primary #303133、--text-secondary #606266、--text-muted #909399 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32（8px 栅格） |
| 圆角 | --radius-sm 6px、--radius-md 10px、--radius-lg 14px |
| 阴影 | --shadow-card、--shadow-hover |
| 字号 | 12 / 13 / 14 / 16 / 20 / 28 / 40 |

### A2 组件（新增 4 个）

| 文件 | 说明 | 关键 API |
|---|---|---|
| components/fx/NumberTicker.vue | 数字滚动 | value、duration、decimals、prefix、suffix |
| components/fx/SpotlightCard.vue | 鼠标光斑容器 | radius、color、disabled |
| components/fx/RevealOnScroll.vue | 滚动渐入 | delay、distance、once |
| components/fx/DotGrid.vue | 点阵背景 | size、opacity |

技术要求：

- NumberTicker 使用 rAF，卸载时取消；prefers-reduced-motion 时直接显示终值。
- SpotlightCard 仅在 pointer: fine 设备启用；用 CSS 自定义属性更新位置，避免状态重渲染。
- RevealOnScroll 使用 IntersectionObserver，进入视口后加 class，不重复触发。

### A3 布局与排版

| 项 | 调整 |
|---|---|
| 页面头部 | 标题 + 面包屑 + 右侧操作区（刷新/导出） |
| 栅格 | 4 列指标卡 + 12 列内容栅格，图表卡支持跨列 |
| 侧边栏 | 分组标题、active 左侧指示条、底部版本信息 |
| 卡片 | 1px 细边框 + 悬停提升 2px；非交互卡不悬停 |
| 留白 | 卡内 20px、卡间 16px、区块间 24px |

### A4 图表统一增强

- 全部图表加 toolbox.saveAsImage（论文/答辩导出）。
- tooltip 统一带单位；坐标轴标签统一万/元/㎡格式。
- 各区均价：加平均线；点击柱状图跳转数据管理并带上区域筛选。
- 年度趋势：标注 2017 年政策节点。
- 特征重要性：默认展示前 8，支持展开全部。
- **修复 P1-1 热力图**：visualMap 显式 dimension: 3；去掉 large: true；色带范围改为 p2–p98（动态计算或 15000–120000）。

## 五、阶段 B：交互增强（1 天）

### B1 预测区间（后端 + 前端）

后端 ml/predictor.py：

- 随机森林含 100 棵树，逐棵树预测 ratio，得到经验分布。
- 返回 p10 / p90 作为 80% 经验区间（非严格置信区间，文档与界面须注明）。
- 新增响应字段：interval_low、interval_high、interval_level。

前端 PredictView：

- 结果卡展示「预测单价 + 区间」与「总价 + 区间」。
- ratio 相对 1.0 的仪表条：<0.9 偏低估、0.9–1.1 接近行情、>1.1 偏高于行情。
- 新增预设：刚需两居、改善三居、学区房（一键填表）。

### B2 数据管理

- 表格支持点击列头排序（面积/总价/单价/成交日期）。
- 筛选条件同步到 URL query，可分享、可后退。
- 表头吸顶，行悬停高亮。
- 修复 P2-8：size-change 只重置页码，由 current-change 统一触发一次加载。

### B3 模型对比

- 每列最优值加金色标记。
- 基线 → 调参显示增减箭头与百分点。
- ES-2 负 R² 增加说明气泡：「价格水平外推失败，属预期结果」。
- 修复 P2-1：ES-4 未纳入调参，表格与图表显示「该实验未调参」占位提示。

### B4 全局状态

- 新增 404 页面。
- 路由切换顶部进度条。
- 接口失败卡片内提供「重试」按钮。
- 修复 P2-4：Dashboard/Analysis 改 Promise.allSettled，单接口失败仅该图卡显示空态。

## 八、风险与应对

| 风险 | 应对 |
|---|---|
| 动画导致低配机器卡顿 | 只用 transform/opacity；尊重 reduced-motion |
| ECharts 按需引入后图表空白 | 逐页验证；漏注册组件会直接报错，构建后人工检查 |
| 预测区间过宽 | 标注为「经验区间」，展示 p10–p90；论文说明非校准置信区间 |
| URL 同步污染路由 | 只同步筛选字段，切换页面时清理 |
| ESLint 规则引入大量告警 | 先只启用 essential 规则，逐步收紧 |

## 九、验收标准

1. npm run build 通过，无错误。
2. 5 个页面无控制台 error，图表全部渲染。
3. 指标卡数字滚动、卡片光斑、区块渐入、点阵背景正常。
4. 系统设置 reduced-motion 时动画关闭。
5. 预测接口返回区间，页面显示「单价 + 区间」。
6. 表格排序、URL 筛选同步可用。
7. ECharts 产物体积下降 ≥ 40%。
8. npm run lint、npm run test 通过。
9. 更新 docs/screenshots/ 下 5 张截图。
10. 热力图颜色梯度正常（蓝→红），非单一颜色。
